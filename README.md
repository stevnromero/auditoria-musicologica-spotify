# 🎵 Auditoría Musical de Preferencias Sonoras en Spotify (N = 238 Pistas)

**Autores:** Steven Romero & Jairo  
**Contexto:** Proyecto de Ciencia de Datos y Programación Aplicada — Primer Semestre (UNAD)  
**Versión:** Edición 4.7 Definitiva  

---

## 📌 1. ¿De qué trata este proyecto?

Este repositorio analiza una playlist de Spotify de **238 canciones** y **187 artistas** aplicando métricas acústicas y Python, alcanzando una puntuación consolidada de **`96.8 / 100` (`9.7 / 10`)** tras integrar 8 pistas de élite (*Linkin Park*, *Bob Sinclar*, *Tony Igy*, *Michael Jackson* y *Maná*) y erradicar al 100 % el circuito urbano comercial (*Karol G*, *Manuel Turizo* y *Feid* en `0` pistas activas).

Puedes consultar la estructura completa, los resultados detallados y el código del proyecto directamente en el repositorio de [auditoria-musicologica-spotify](https://github.com).
